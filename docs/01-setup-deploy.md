# دليل الإعداد والنشر والتحديث — منصة ابن خلدون للتدريب والتطوير المهني (الإصدار 3.0)

> البيئة: Google Apps Script (الخادم) + Google Sheets (البيانات) + Google Drive (الشهادات والصور) + HTML/CSS/JS (الواجهة المقدَّمة من تطبيق الويب نفسه عبر `google.script.run`).

## 1) ما الذي تحتاجه قبل البدء
- حساب Google سيُنشر منه التطبيق (يُفضَّل حساب Google Workspace الخاص بالمدرسة؛ يعمل أيضًا على حساب Gmail شخصي مع حصة بريد أقل).
- هذا الحساب هو الذي سيُرسل البريد الإلكتروني (رموز التفعيل، الدعوات، الشهادات) وسيملك جدول البيانات ومجلد الملفات.
- اختياريًا: مفتاح Anthropic API لتفعيل التوليد الآلي للورش (المسار اليدوي والهيكل الأولي يعملان بدونه).

## 2) طريقتان للتثبيت

### الطريقة (أ): اللصق في محرر Apps Script — ملفان فقط
1. افتح https://script.google.com وأنشئ مشروعًا جديدًا باسم «منصة ابن خلدون للتدريب».
2. افتح ملف `Code.gs` في المحرر، احذف محتواه، والصق محتوى `dist/Code.gs` كاملًا.
3. من القائمة **+** أضف ملف **HTML** باسم `index` (بدون امتداد) والصق محتوى `dist/index.html` كاملًا.
4. من **إعدادات المشروع** (⚙️) فعّل «إظهار ملف البيان appsscript.json في المحرر»، ثم استبدل محتواه بمحتوى `dist/appsscript.json` (المنطقة الزمنية Asia/Qatar والنطاقات المطلوبة).
5. احفظ (Ctrl+S).

### الطريقة (ب): النسخة المقسمة عبر clasp (للمطورين)
```bash
npm install -g @google/clasp
clasp login
clasp create --type standalone --title "منصة ابن خلدون للتدريب" --rootDir src
clasp push
```
الملفات في `src/` تُرفع كما هي (ملفات `.gs` متعددة + `index.html` + ملفات التضمين `Styles/Assets/AppCore/AppAuth/AppTrainee/AppAdmin/AppAdmin2`). يحلّ Apps Script التضمينات عبر `include()` عند تقديم الصفحة.

> ملاحظة: الطريقتان متكافئتان وظيفيًا. يولَّد `dist/` من `src/` بالأمر `node tools/build.js`، فلا تعدّل `dist/` يدويًا.

## 3) التهيئة الأولى (مرة واحدة)
1. في المحرر اختر الدالة **`SETUP_1_initialize`** من قائمة الدوال واضغط **تشغيل (Run)**.
2. وافق على الأذونات المطلوبة (Sheets، Drive، إرسال البريد، الاتصال الخارجي، المشغّلات).
3. افتح **سجل التنفيذ (Execution log)**. ستجد:
   - رابط جدول البيانات الذي أُنشئ باسم «IKP - قاعدة بيانات منصة ابن خلدون للتدريب».
   - **رمز الإعداد للمدير الأول** (8 أرقام، صالح 24 ساعة). لا يُخزَّن هذا الرمز إلا مجزّأً، وهو إثبات ملكية المشروع.
4. ما الذي تفعله الدالة: تنشئ 13 جدولًا بالأعمدة المعتمدة، ومجلد Drive «IKP - ملفات منصة ابن خلدون للتدريب»، ومفتاح تجزئة خادميًا لكلمات المرور (pepper)، وتزرع الورشة الأولية «صياغة الأهداف السلوكية والتخطيط الفعّال للدروس» منشورة. إعادة تشغيلها آمنة ولا تكرر شيئًا.

## 4) النشر كتطبيق ويب
1. **نشر → نشر جديد (Deploy → New deployment)** → النوع: **تطبيق ويب (Web app)**.
2. الإعدادات:
   - **التنفيذ باسم (Execute as):** أنا (حساب الناشر) — ضروري حتى يصل الجميع إلى جدول البيانات والبريد عبر حساب واحد.
   - **من يمكنه الوصول (Who has access):** أي شخص (Anyone) — صفحة الدخول هي التي تتحقق من الهوية، وجميع الإجراءات محمية على الخادم برمز جلسة.
3. انسخ **رابط تطبيق الويب** (ينتهي بـ `/exec`). هذا هو رابط المنصة الذي يُوزَّع على الكادر.

## 5) إنشاء المدير الأول
1. افتح رابط تطبيق الويب. ستظهر صفحة **«إعداد المدير الأول»** تلقائيًا ما دام لا يوجد مدير نشط.
2. أدخل رمز الإعداد من السجل، والاسم، والبريد، وكلمة المرور (8 أحرف على الأقل بحروف وأرقام).
3. يُفعَّل الحساب بصلاحية «مدير» ويُحوَّل للوحة الإدارة. يُستهلك الرمز فورًا.
4. إن فُقد الرمز أو انتهت صلاحيته: شغّل `SETUP_3_regenerateSetupToken` من المحرر. الدالة نفسها تصلح لترقية حساب موجود (بالبريد نفسه) إلى مدير عند فقدان جميع حسابات المدراء.
5. **لا يوجد أي حساب أو كلمة مرور ثابتة في الكود.** لا تُمنح الصلاحية الإدارية لبريد مدرج في قائمة دون إثبات: المدراء الإضافيون يُضافون من لوحة الإدارة بحالة «بانتظار التفعيل» ويصلهم رمز دعوة لتعيين كلمة المرور قبل أي صلاحية.

## 7) المشغّل الزمني للبريد (موصى به)
شغّل `SETUP_4_installMailRetryTrigger` مرة واحدة من المحرر. يثبّت مشغّلًا كل ساعة (`cronRetryMail`) يعالج قائمة انتظار البريد (عندما تتجاوز الدعوات حد الدفعة الواحدة = 40 رسالة) ويعيد إرسال الرسائل الفاشلة (مثل تعذر إرسال شهادة). يمكن أيضًا تنفيذ ذلك يدويًا من **سجل العمليات → سجل البريد → معالجة قائمة الانتظار**.

## 8) التحقق من الإعداد
شغّل `DIAG_checkEnvironment` من المحرر: يطبع حالة قاعدة البيانات وعدد السجلات، المجلد، مفتاح التجزئة، مفتاح Anthropic، حصة البريد المتبقية اليوم، المشغّل، رابط النشر، وعدد المدراء النشطين — دون أي تعديل.

## 9) التحديث إلى إصدار جديد
1. خذ نسخة احتياطية من لوحة الإدارة (سجل العمليات → النسخ الاحتياطي → تنزيل JSON)، ويُستحسن أيضًا نسخ جدول البيانات من Drive.
2. استبدل محتوى `Code.gs` و`index` بالملفات الجديدة (أو `clasp push`).
3. شغّل **`SETUP_5_migrate`** من المحرر: يضيف الأعمدة الناقصة في نهاية الجداول ويدمج مفاتيح الإعدادات الجديدة دون الكتابة فوق القيم الحالية. غير مدمر، ويمكن إعادته بأمان.
4. **نشر → إدارة عمليات النشر → تعديل → الإصدار: جديد → نشر** حتى يبقى الرابط نفسه ويأخذ الكود الجديد. (نشر «جديد» بالكامل يُنتج رابطًا مختلفًا.)
5. افتح المنصة وتحقق من لوحة الإدارة → نظرة عامة.

### الترقية من الإصدار 2.x (النسخة المرجعية)
- بنية الجداول متطابقة؛ لا حاجة لنقل البيانات. يكفي استبدال الملفين وتشغيل `SETUP_5_migrate`.
- **مهم:** كلمات المرور مجزّأة بمفتاح خادمي (pepper) محفوظ في Script Properties للمشروع نفسه. إذا حدّثت الكود داخل **المشروع نفسه** تبقى كلمات المرور صالحة. أما إذا أنشأت مشروع Apps Script **جديدًا** وربطته بجدول البيانات القديم، فستفشل كلمات المرور القديمة ويحتاج المستخدمون إلى «نسيت كلمة المرور» — أو انقل قيمة الخاصية `IKP_PASSWORD_PEPPER` من المشروع القديم إلى الجديد قبل أول دخول (إعدادات المشروع → خصائص البرنامج النصي).
- لربط مشروع جديد بجدول قديم: أضف الخاصية `IKP_SPREADSHEET_ID` بمعرّف الجدول و`IKP_DRIVE_FOLDER_ID` بمعرّف المجلد قبل تشغيل `SETUP_1_initialize`.

## 10) خصائص البرنامج النصي (Script Properties) المستخدمة
| الخاصية | المعنى | تُضبط بواسطة |
|---|---|---|
| `IKP_SPREADSHEET_ID` | معرّف جدول البيانات | SETUP_1 (أو يدويًا للربط بجدول قائم) |
| `IKP_DRIVE_FOLDER_ID` | مجلد الشهادات والصور | SETUP_1 |
| `IKP_PASSWORD_PEPPER` | مفتاح تجزئة كلمات المرور | SETUP_1 (تلقائيًا) — **لا تحذفه** |
| `IKP_SETUP_TOKEN_HASH` / `IKP_SETUP_TOKEN_EXP` | رمز الإعداد المجزّأ وانتهاؤه | SETUP_1 / SETUP_3، يُحذف بعد الاستخدام |
| `IKP_ANTHROPIC_API_KEY` / `IKP_ANTHROPIC_API_KEY_AT` | مفتاح Claude وتاريخ ضبطه | لوحة الإدارة أو SETUP_2 — **لا يُعاد للمتصفح أبدًا** |
| `IKP_WEBAPP_URL` | رابط النشر (لروابط التحقق في الشهادات والبريد) | تلقائيًا عند أول فتح |
| `IKP_SCHEMA_VERSION` | إصدار بنية الجداول | SETUP_1 / SETUP_5 |

## 11) الأذونات (appsscript.json)
`spreadsheets` (البيانات)، `drive` (المجلد والملفات)، `script.send_mail` (البريد)، `script.external_request` (Claude API)، `script.scriptapp` (المشغّلات ورابط النشر)، `userinfo.email`. المنطقة الزمنية `Asia/Qatar`، بيئة التشغيل V8.
