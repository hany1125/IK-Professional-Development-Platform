# تقرير الاختبار — الإصدار 3.0.0 (تاريخ التنفيذ: 2026-11-07)

## منهجية الاختبار
- **لا يمكن تشغيل Google Apps Script خارج Google**، لذلك بُني محاكٍ لخدماته (`tests/gas-mock.js`) يشغّل كود الخادم الحقيقي (`src/*.gs`) داخل Node.js: أوراق Sheets في الذاكرة مع التحويل التلقائي للقيم كما تفعل Sheets (TRUE/FALSE، الأرقام، التواريخ)، خصائص البرنامج النصي، الكاش مع انتهاء الصلاحية، القفل، التجزئة والتوقيع HMAC وBase64 وUUID وتنسيق التاريخ، البريد (صندوق صادر + حصة + إجبار الفشل)، الاتصال الخارجي (معالج قابل للبرمجة يحاكي Claude API)، Drive، قوالب HTML، المشغّلات، وساعة قابلة للتقديم.
- **اختبارات القبول الخادمية** (`tests/server.test.js`): 15 اختبارًا تغطي قائمة القبول في المواصفات. التشغيل: `npm test`.
- **الاختبارات الشاملة** (`tests/e2e.js`): خادم تطوير يقدّم الواجهة الحقيقية (`index.html` بكل تضميناتها) ويحوّل `google.script.run` إلى الخادم المحاكى، ومتصفح Chromium عبر Playwright ينفّذ 16 خطوة على عرض 1280px و390px مع لوحة المفاتيح، ويلتقط 24 لقطة شاشة وملف PDF للشهادة في `tests/screenshots/`. التشغيل: `npm run test:e2e`.
- **فحوص ثابتة** (`tools/check.js`): صياغة كل الملفات، تطابق استدعاءات الواجهة مع إجراءات الخادم (64 إجراء)، عدم وجود أسرار أو بريد شخصي في الكود، عدم تسريب مفتاح الإجابة في بيانات المتدرب. التشغيل: `npm run check`.

## غير منفذ هنا (يتطلب حسابًا خارجيًا أو بيئة Google الفعلية) — وخطوات التحقق
| البند | السبب | كيف تتحقق بعد النشر |
|---|---|---|
| إرسال البريد الفعلي عبر MailApp (الوصول، المرفق، اسم المرسل، عدم الوقوع في البريد المزعج) | يحتاج حساب Google | سجّل حسابًا تجريبيًا ببريد مسموح وتحقق من وصول رمز التفعيل؛ اجتز الورشة وتحقق من وصول الشهادة والنسخة الإدارية؛ راجع «سجل البريد» |
| سلامة الخط العربي في PDF الخادم (`getAs('application/pdf')`) | المحوّل داخلي لدى Google | نزّل PDF من «شهاداتي» وافتحه؛ إن ظهرت الحروف منفصلة أو معكوسة فاستخدم «طباعة / حفظ PDF من المتصفح» (انظر القيود) |
| الاتصال الحقيقي بـ Claude API (المفتاح، النموذج، زمن الاستجابة ضمن حد التنفيذ) | يحتاج مفتاح Anthropic | الإعدادات → أدخل المفتاح → «اختبار الاتصال»؛ ثم ولّد ورشة من وحدتين وراقب المراحل |
| أداء Sheets الحقيقي وزمن القفل تحت تزامن عدة مستخدمين | المحاكي لا يحاكي زمن استجابة Google | راقب `ms` في استجابات الواجهة (مطبوعة في الاستجابة) وزمن التنفيذ في Apps Script → عمليات التنفيذ |
| عرض الصفحة داخل iframe تطبيق الويب (googleusercontent) وخط Cairo من Google Fonts | بيئة التشغيل الفعلية | افتح رابط /exec على حاسوب وهاتف؛ تحقق من الخط والتمرير |
| حصة البريد اليومية وسلوك المشغّل الزمني كل ساعة | زمن حقيقي | شغّل SETUP_4 وراقب «حصة البريد المتبقية» وقائمة الانتظار بعد ساعة |
| التنزيل والطباعة على متصفحات Safari/iOS | غير متاحة في بيئة الاختبار | جرّب تنزيل PDF والطباعة من iPhone |

## كيفية إعادة تشغيل الاختبارات
```bash
npm test          # اختبارات الخادم (Node 18+)
npm run test:e2e  # الاختبارات الشاملة (يتطلب Chromium عبر Playwright)
npm run check     # الفحوص الثابتة
npm run dev       # خادم تطوير محلي على http://localhost:4173 (يطبع رمز الإعداد في الطرفية)
```
