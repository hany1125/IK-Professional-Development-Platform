# منصة ابن خلدون للتدريب والتطوير المهني — الإصدار 3.0.0

**الجهة:** مدرسة ابن خلدون الإعدادية للبنين — دولة قطر · **الفئة:** المعلمون والكادر المدرسي · **الرؤية:** متعلم ريادي لتنمية مستدامة

منصة تدريب إلكتروني عربية (RTL) تعمل على Google Apps Script + Google Sheets + Google Drive، بواجهة مقدَّمة من تطبيق الويب نفسه عبر `google.script.run`. تغطي: الحسابات والصلاحيات، الورش والوحدات، الاختبارات المرحلية والنهائية (تقييم على الخادم)، الشهادات (PDF + QR للتحقق + بريد)، التقارير والتصدير، توليد الورش بالذكاء الاصطناعي (Claude) بثلاثة مسارات، النسخ الاحتياطي والاستعادة، وسجل العمليات.

## البدء السريع (5 خطوات)
1. أنشئ مشروع Apps Script، الصق `dist/Code.gs` في `Code.gs` و`dist/index.html` في ملف HTML باسم `index`، واستبدل `appsscript.json` بمحتوى `dist/appsscript.json`.
2. شغّل `SETUP_1_initialize` من المحرر ووافق على الأذونات؛ انسخ **رمز الإعداد** من سجل التنفيذ.
3. انشر كتطبيق ويب: التنفيذ باسمي، الوصول لأي شخص. انسخ رابط `/exec`.
4. افتح الرابط → «إعداد المدير الأول» → أدخل الرمز والاسم والبريد وكلمة المرور.
5. من لوحة الإدارة → الإعدادات: البريد الإداري، النطاقات، مفتاح Claude (اختياري). شغّل `SETUP_4_installMailRetryTrigger` لمعالجة البريد تلقائيًا.

## التطوير والاختبار محليًا
```bash
npm run check      # فحوص ثابتة
npm test           # 15 اختبار قبول للخادم داخل محاكي Apps Script
npm run test:e2e   # 16 خطوة في Chromium (حاسوب + هاتف + لوحة مفاتيح) + لقطات في tests/screenshots
npm run dev        # خادم تطوير محلي: http://localhost:4173 (يطبع رمز الإعداد)
npm run build      # إعادة توليد dist/ بعد أي تعديل في src/
```
> تعديل الصور الافتراضية: ضع الملفات في `assets/` ثم `npm run assets && npm run build`.

## مبادئ ثابتة في التصميم
- كل إجراء يمر عبر `api()` على الخادم مع التحقق من الجلسة والصلاحية؛ إخفاء الأزرار ليس حماية.
- المتصفح يرسل الإجابات ومعرّف المحاولة فقط؛ الدرجة والنجاح والشهادة تُحسب وتُصدر على الخادم من إصدار محدد من المحتوى.
- التخزين المحلي للتجربة فقط؛ المرجع المعتمد هو Google Sheets.
- لا أسرار في الكود: مفتاح Claude وpepper ورمز الإعداد في Script Properties ولا تُعاد للمتصفح.
- فشل البريد لا يُفشل النجاح؛ كل رسالة لها حالة مستقلة وإعادة محاولة.
- المحتوى المولَّد بالذكاء الاصطناعي يُحفظ مسودة دائمًا ولا يُنشر إلا بعد مراجعة بشرية وتحقق آلي.
